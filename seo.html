All Filvora Tools — Full Directory

This page lists every tool on Filvora with a direct link. Each tool runs entirely in your browser — no files are uploaded to a server.

File Information

  • File Extension Checker — Inspect a file’s name, extension, MIME type, size and category.
  • MIME Type Checker — Detect a file’s MIME type, extension, category and size.
  • File Type Identifier — Identify a file’s type with a plain-language description.
  • File Metadata Viewer — View the metadata your browser exposes for any file: size, type, dates, image dimensions.
  • File Path / Filename Analyzer — Break a file path or file name down into its parts.

File Management

  • Duplicate File Name Finder — Select multiple files and find ones that share the same file name.
  • File Name Cleaner — Tidy up messy file names: extra spaces, symbols, casing and separators.
  • File Name Generator — Generate a batch of consistent, professional file names.
  • File Extension Extractor — Upload multiple files and pull out a clean list of their extensions.
  • File List Generator — Build an exportable list of file names, types and sizes.
  • Batch File Renamer — Preview batch rename rules, then download a rename list or a ZIP of renamed copies.

File Security

  • File Hash Generator — Calculate SHA-1, SHA-256, SHA-384 and SHA-512 hashes for any file.
  • Hash Checker / Integrity Checker — Verify a file’s SHA-256 hash against an expected value.

File Compression

  • ZIP File Creator — Bundle multiple files into a real .zip archive, entirely in your browser.
  • ZIP File Extractor — Open a .zip archive in your browser and download the files inside.

File Conversion

  • File Size Converter — Convert between Bytes, KB, MB, GB and TB — decimal and binary.
  • File Timestamp Converter — Convert between Unix timestamps and human-readable dates.
  • File Type Converter — Convert plain text and data between TXT, HTML, JSON, CSV and Markdown.

File Analysis

  • File Size Calculator — Estimate total storage from a file count and an average file size.
  • File Size Comparison Tool — Compare multiple files side by side: smallest, largest, average and total.
